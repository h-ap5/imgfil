# FILTER_2000.exe

브라우저에서 사진을 불러와 레트로 필터를 적용하고 PNG 또는 WEBP로 저장하는 정적 웹앱입니다. 사진은 서버로 전송되지 않으며 모든 처리는 사용자의 브라우저 안에서 이루어집니다.

## 포함된 필터

- 흐릿한 아이폰 — 낮은 대비, 소프트 블룸, 옅은 분홍빛
- Y2K 앰버 — 2000년대식 누런 색감, 중앙 플래시, 비네트
- 아날로그 TV — RGB 채널 어긋남, 노이즈, 스캔라인
- 일회용 플래시 — 강한 중앙 플래시, 거친 입자, 어두운 가장자리
- 블루 CCD — 차가운 색감, 디지털 블룸, 푸른 그림자
- 네온 용해 — 전체 유동 왜곡 또는 사진을 직접 누르고 문질러 적용하는 국소 브러시, 적·청 네온 색분리
- 신호 붕괴 — RGB 채널 이탈, 화면 찢김, 신호 누락 블록
- 프레임 잔상 — 반복되는 피사체 잔상과 압축 코덱 번짐
- 프리즘 잔상 — 유리 굴절처럼 겹치는 무지개빛 다중상
- 열화상 블룸 — 밝기에 반응하는 거짓 색상과 발광
- 복사기 레이브 — 거친 흑백 토너와 형광 연두 잉크
- 리소 어긋남 — 청색·주홍색 망점과 인쇄판 어긋남
- 셀 만화 — 단순화된 색면과 검은 윤곽선
- 홀로 드림 — 청록·라벤더·분홍 진주광과 몽환적인 블룸

## 스티커 꾸미기

- 홀로 팩 — 크롬 하트, 젤리 별, 유리 달, 나비, 꽃, 폴더폰 등 10종
- 픽셀 팩 — YES/NO 버튼, 커서, 별 폭발, 선택 하트, ENTER 키, 플레이어, 오류창 등 10종
- 내 이미지 — 배경을 제거한 PNG·WEBP·JPG·SVG를 사용자 스티커로 추가
- 스티커 추가, 랜덤 배치, 드래그 이동, 크기·회전 조절, 선택 테두리 × 삭제, 선택 삭제, 전체 삭제
- 미리보기와 PNG·WEBP 다운로드에 동일한 위치와 크기로 합성

## 저장 및 네온 용해

- 저장 전 PNG 또는 WEBP 선택
- 네온 용해의 전체/브러시 범위 전환
- 브러시 크기 조절, 한 획 취소, 전체 브러시 효과 지우기
- 전체 네온 용해는 강도 50% 이후 변화가 완만해지도록 조정

## 로컬 실행

빌드 과정이나 패키지 설치가 필요 없습니다. `index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 로컬 서버가 필요하다면 이 폴더에서 다음 명령을 실행하세요.

```bash
npx serve .
```

## GitHub Pages 배포

1. 이 폴더의 파일을 GitHub 저장소 루트에 올립니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택합니다.
4. 배포할 브랜치와 `/ (root)`를 선택한 뒤 저장합니다.

별도 API 키, 서버, 환경 변수는 필요하지 않습니다.
