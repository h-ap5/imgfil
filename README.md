# FILTER_2000.exe

브라우저에서 사진을 불러와 레트로 필터를 적용하고 PNG 또는 WEBP로 저장하는 정적 웹앱입니다. 사진은 서버로 전송되지 않으며 모든 처리는 사용자의 브라우저 안에서 이루어집니다.

## 편집 화면

- 위쪽 메뉴 바에 필터 · 조정 · 스티커 · 글자 · 프레임 탭과 원본 비교 · PNG/WEBP · 저장 버튼
- 미리보기 바로 아래 가로 필터 줄: 불러온 사진에 각 필터를 입힌 썸네일로 보여 주고, 강도·그레인을 바꾸면 썸네일도 다시 그림
- 오른쪽 설정 창에는 고른 탭의 설정만 표시하고, ×로 닫으면 미리보기가 넓어짐
- 넓은 화면에서는 한 화면 안에 모두 들어가 페이지를 위아래로 스크롤하지 않고 편집
- 태블릿은 한 열 배치, 휴대폰은 아래 고정 탭 바와 아래에서 올라오는 설정 시트(같은 탭을 다시 누르거나 ×로 닫기)

## 포함된 필터

- 필터 없음 — 원본 그대로 두고 틀·자막·스티커만 쓰기
- 흐릿한 아이폰 — 낮은 대비, 밝은 부분만 번지는 소프트 글로우, 옅은 분홍빛
- Y2K 앰버 — 2000년대식 누런 색감, 따뜻한 하이라이트 글로우, 어두운 모서리
- 아날로그 TV — RGB 채널 어긋남, 노이즈, 스캔라인
- 일회용 플래시 — 진한 대비, 붉게 번지는 하이라이트, 거친 필름 입자, 어두운 가장자리
- 블루 CCD — 차가운 색감, 밝은 부분의 디지털 블룸, 푸른 그림자
- 네온 용해 — 전체 유동 왜곡 또는 사진을 직접 누르고 문질러 적용하는 국소 브러시, 적·청 네온 색분리
- 신호 붕괴 — RGB 채널 이탈, 화면 찢김, 신호 누락 블록
- 프레임 잔상 — 반복되는 피사체 잔상과 압축 코덱 번짐
- 프리즘 잔상 — 대각선으로 갈라지는 적·청 채널, 색이 나뉜 옅은 잔상, 무지개빛 글로우
- 열화상 블룸 — 밝기에 반응하는 거짓 색상과 발광
- 복사기 레이브 — 절제된 흑백 토너 질감과 형광 연두 잉크
- 리소 어긋남 — 청색·주홍색 망점과 인쇄판 어긋남
- 흑백 만화 — 밝게 정돈한 완전 흑백 잉크, 가는 윤곽선, 성긴 사선 해칭
- 드림코어 — 리미널 스페이스 느낌의 뿌연 헤이즈, 청록 그림자와 분홍 하이라이트, 소프트 포커스, 가장자리 안개와 색번짐
- 픽셀 블록 — 큰 픽셀 블록과 제한된 색상 팔레트
- 청량 필름 — 쨍한 청록색, 왼쪽 빛샘, 인화 가장자리, 세로 날짜
- 빛바랜 기억 — 낮은 채도, 들뜬 검정, 푸른 회색 그림자, 오른쪽 빛샘
- 크림 뽀샤시 — 부드러운 확산광, 밝은 부분의 크림빛 글로우, 따뜻한 크림·분홍빛
- 하트 보케 — 사진 속 밝은 광원을 찾아 색수차가 있는 하트 빛망울로 변환
- 밀키 포트레이트 — 밝고 뿌연 저대비 인물 보정
- 핑크 하트 터널 — 분홍 동심 하트 텍스처를 사진과 섞고 가운데는 비워 인물을 가리지 않음

## 스티커 꾸미기

- 홀로 팩 — 크롬·오팔 스티커 14종과 하늘색 파스텔 3D 스티커 16종(하늘 달, 말랑 별, 진주 조개, 젤리 곰, 하트 행성, 곰돌이 등), 총 30종
- Y2K 팩 — 젤리 하트, 폴더폰, 글로시 입술, CD, 카세트테이프, 디지털 펫, 립글로스 등 18종
- 픽셀 팩 — YES/NO 버튼, 커서, 별 폭발, 오류창, 로딩 친구, 도트 폴더폰, 하트 펫 등 15종
- 홀로·Y2K 팩은 이 사이트용으로 새로 렌더링한 입체 스티커(`assets/stickers`)이며, 스티커 탭을 처음 열 때 불러옴
- 내 이미지 — 배경을 제거한 PNG·WEBP·JPG·SVG를 사용자 스티커로 추가
- 스티커 추가, 랜덤 배치, 드래그 이동, 크기·회전 조절, 선택 테두리 × 삭제, 선택 삭제, 전체 삭제
- 선택한 스티커의 오른쪽 아래 핸들을 드래그해 캔버스에서 바로 크기 조절
- 미리보기와 PNG·WEBP 다운로드에 동일한 위치와 크기로 합성

## 영화 자막

- 위아래 검은 레터박스와 직접 고칠 수 있는 자막(줄을 바꾸면 두 줄 자막)
- 글꼴: IM혜민체(기본), 조선굴림, DX영화자막
- DX영화자막은 라이선스상 사이트에 넣을 수 없어서, PC에 설치돼 있으면 바로 쓰고 없으면 폰트 파일을 직접 불러와 이 브라우저에만 저장 (i 버튼에 설치 안내)
- 글자 색(노랑·흰색 버튼과 직접 선택), 글자 크기, 레터박스 두께, 자막 위치(화면 안 / 아래 검은 띠)

## 저장 및 네온 용해

- 저장 전 PNG 또는 WEBP 선택
- 네온 용해의 전체/브러시 범위 전환
- 브러시 크기 조절, 짧은 클릭·드래그의 파동 왜곡, 길게 누를수록 강해지는 회전 꼬임
- 브러시 횟수 제한 없이 계속 덧칠 가능하며, 오래된 경로는 가중치를 유지한 채 자동 압축
- 한 획 취소, 전체 브러시 효과 지우기
- 전체 네온 용해는 강도 50% 이후 변화가 완만해지도록 조정
- 네온 용해·신호 붕괴·프레임 잔상의 패턴 위상 조절 및 랜덤 변경

## 오버레이와 필름 스트립

- 아이폰 카메라 앱처럼 그린 한국어/영문 카메라 화면(초점 상자, 배율 버튼, 촬영 모드 줄, 셔터, 사진 가로·세로에 맞춘 배치)
- LCD 글자, AF 괄호, 배터리·남은 매수, 주황색 날짜가 있는 디카 화면
- 카메라·디카 화면의 좌우 90도 연속 회전(0°·90°·180°·270°)
- 고해상도 복원 에셋을 사용하고 편집 결과가 실제 LCD 영역 안에 들어가는 가로 디카·세로 핑크 디카 프레임
- 확대해도 깨지지 않는 SVG 고전 그림판 프레임과 체커보드 작업 영역 합성
- 사진을 고전 창 내부에 배치하는 XP 데스크톱 합성
- 채팅 없이 사진을 플레이어 안에 합성하는 YouTube·Twitch 스트리밍 화면
- YouTube 밝은/어두운 테마, 편집 가능한 방송 제목·채널명·시청자 수·방송 시간과 항목별 표시 전환
- 스트리밍 플레이어 안에서 사진 화면 채우기/전체 보기, 확대, 가로·세로 위치 조절
- 2~6칸 빈티지 필름 스트립
- 기본값은 현재 사진 반복, 여러 이미지를 선택하면 앞 칸부터 개별 사진 배치
- 각 칸의 썸네일을 눌러 사진 교체, 화살표로 순서 이동, ×로 해당 칸만 비우기
- 날짜 스탬프는 오늘 날짜가 기본이며 날짜 입력으로 원하는 날짜 지정

## 미연시 합성

- 이름과 대사를 따로 입력하는 대화창 모드
- 클래식·핑크·사이버 대화창과 Mona12·명조 글꼴 선택
- 대화창·이름표 색상을 각각 선택하고 디자인 기본색으로 되돌리기
- 이름은 길이에 따라 늘어나는 이름표 중앙에 배치하고, 아주 긴 이름은 잘리지 않도록 자동 축소
- 대사의 상단·좌측 여백과 진행 삼각형의 우측·하단 여백을 각각 같은 값으로 배치
- 배경 이미지와 투명 PNG·WEBP 캐릭터를 따로 불러오는 장면 합성 모드
- 누끼 캐릭터의 크기와 가로 위치 조절

## 로컬 실행

빌드 과정이나 패키지 설치가 필요 없습니다. 다만 크롬 등 일부 브라우저는 `index.html`을 파일로 직접 열면 스티커·프레임 이미지가 합성된 사진의 저장을 막으므로, 이 폴더에서 로컬 서버를 띄워 여는 것을 권장합니다.

```bash
npx serve .
```

## GitHub Pages 배포

1. 이 폴더의 파일을 `assets` 폴더까지 통째로 GitHub 저장소 루트에 올립니다. 디카·그림판 프레임은 `assets/digicam-horizontal-hq.png`, `assets/digicam-portrait.png`, `assets/paint-frame-hq.svg`를, 스티커는 `assets/stickers/`를 사용합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택합니다.
4. 배포할 브랜치와 `/ (root)`를 선택한 뒤 저장합니다.

별도 API 키, 서버, 환경 변수는 필요하지 않습니다. 자막 글꼴(IM혜민체·조선굴림)과 카메라 화면 글꼴은 공개 웹폰트 CDN에서 불러옵니다.

`index.html`에는 정적 파일 버전값이 포함되어 있어 업데이트 후 이전 JavaScript가 캐시에 남아 새 버튼이 무반응이 되는 문제를 방지합니다.
